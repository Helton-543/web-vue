# 赞助收款码

`wechat.png` / `alipay.png` 是随扩展分发的收款码，展示在「赞助作者」面板里。

## 当前图片

| 文件         | 来源         | 说明                                                                  |
| ------------ | ------------ | --------------------------------------------------------------------- |
| `wechat.png` | 微信赞赏码   | 中心原来的插画已替换为**微信品牌图标**（绿色圆角方块 + 双气泡）       |
| `alipay.png` | 支付宝收款码 | 中心原来的头像已替换为**支付宝品牌图标**（蓝色圆角方块 + 白色「支」） |

替换是用 `tools/make-sponsor-qr.py` 做的：只覆盖原头像那块，二维码其余部分逐像素不动，
支付宝原图与改后图解码出的内容完全一致（`tools/verify-edit.py` 校验）。

## 换成自己的收款码

```bash
python tools/make-sponsor-qr.py 我的支付宝.png 我的微信.png media/sponsor
python tools/verify-edit.py 我的支付宝.png media/sponsor/alipay.png
```

脚本会自动定位中心头像（按「中间调色块 + 离中心最近」的连通域判断），用品牌色方块覆盖，
并保留四周的二维码区域。依赖：`pip install pillow opencv-python-headless`。

> 微信赞赏码是微信自己的点阵风格，通用二维码解码器（OpenCV / jsQR）本来就解不出来，
> 所以脚本对它能做的只有「改动范围校验」——换完请用微信扫一次确认。

## 境外赞赏（链接通道）

微信/支付宝的二维码境外用户扫不了（要各自的 App），所以面板额外支持一个**纯链接通道**：

1. 选一个「境外能付、你也能提现」的方式：

   | 方式                        | 付款方需要什么                   | 建议                                                                                   |
   | --------------------------- | -------------------------------- | -------------------------------------------------------------------------------------- |
   | **PayPal.me**               | 有卡即可（guest 结账，不必注册） | 中国大陆个人最容易落地，`paypal.me/<用户名>` 一行链接即可；提现走银行/连连，手续费偏高 |
   | **Ko-fi / Buy Me a Coffee** | 有卡即可                         | 页面好看、支持一次性/月付；收款端要绑 Stripe 或 PayPal                                 |
   | **爱发电 / Afdian**         | 微信/支付宝为主                  | 国内体验最好，但境外受众仍要支付宝                                                     |
   | ~~GitHub Sponsors~~         | —                                | **中国大陆暂不支持收款**（需支持地区的 Stripe/银行账户），别选                         |

2. 把链接写进两处（一条命令搞定）：

   ```bash
   node tools/set-sponsor-link.mjs https://paypal.me/yourname
   ```

   它会同时改 `media/sponsor/config.json` 的 `overseas.link`（面板卡片）和
   `package.json` 的 `sponsor.url`（VS Code 扩展页 / 商店页的 **Sponsor** 按钮）。
   清空用 `--clear`。

3. `overseas.link` 为空时面板**不显示**这张卡片——不会留一张点不动的死卡片。

## 渠道配置

`config.json` 里 `label` 留空时使用扩展内置文案（微信 / 支付宝，随界面语言切换）；
`link` 可填公网打赏页（如爱发电），面板会在二维码下显示「打开链接」。
